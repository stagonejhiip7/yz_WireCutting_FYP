Daily use · last 14 days

Wire used by each group

m

Every group shares one wire limit. The machine adds up the wire length of every job cut by the group's students and refuses a job that would go past the limit. "Reset usage" starts counting from zero again (e.g. for a new semester) - the job history is kept. Students with no group and admin emails have no limit. Put students in groups on the Access list tab.

Students in groups

Who used how much wire

Wire length = (insulator + front + back strip) × quantity, summed over every job. Jobs from before this was recorded count as 0 m.

Add students

Simplest: type one student per line as group,email - e.g. ME01,abcd0001@student.monash.edu - here or in a .csv file. You can also write a group name on its own line and list its emails underneath. The student template adds optional name and student ID columns (group, name, student_id, email); allowed_students.csv uses the same columns, so you can download it, edit it and upload it again. Uploading a student again moves them to the new group. Only the email decides who can use the machine; the group decides whose wire limit a job counts against.

Time per wire, by strip mode

Time per wire = start of the feed until the wire is ejected. Mean ± SD is pooled over every wire of that mode. Mode is what actually ran (a Pull row over 5 cm runs as No-pull).

Colour change

Colour change = retract the old wire + home the new one. First load = homing at the start of a job (nothing to retract).
